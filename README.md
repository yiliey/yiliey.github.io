# yiliey.github.io

A portfolio — experience, projects, publications, education and awards.

**Live:** https://yiliey.github.io

## Editing

Content lives in `content/` (`*.toml`, `bio.md`, `publications.bib`). Push to
`main` and GitHub Actions builds and deploys.

## Running locally

```bash
npm ci
npm run dev
```
